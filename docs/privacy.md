# 隐私政策

**扩展名称**：小红书下载器（RedNote Downloader）
**适用版本**：1.3.2 及以后
**生效日期**：2026-10-25

---

## 一句话

**本扩展不收集、不上传、不共享任何数据。** 所有事情都发生在你的浏览器里。

## 一、我们收集哪些信息

**不收集任何信息。**

本扩展没有账号、没有服务器、没有埋点、没有统计。它不收集你的个人信息、
浏览历史、笔记内容、下载记录或任何形式的使用数据，也不会把这些数据传给任何人。

## 二、权限用途

| 权限 | 用途 |
| --- | --- |
| `downloads` | 把解析出来的视频和图片保存到你自己的下载目录。 |
| `storage` | 在本机保存你的设置（保存路径、命名模板、图片格式、并发数、界面偏好）和最近 50 条下载任务的完成情况。这些数据只存在你的浏览器里。 |
| `offscreen` | 文件多的时候需要把几百个文件打包成一个 zip。Chrome 要求这类批量文件操作在离屏文档里完成，所以用到这个权限。 |
| 主机权限 `https://*.xiaohongshu.com/*` | 只在小红书网页上读取页面**已经加载过的**数据，从中解析出视频和图片的下载地址。它不会抓取你在其它网站上的任何内容。 |

## 三、数据流向

下载的内容会保存在**你自己浏览器的下载目录**里 —— 也就是你电脑上的普通文件夹，
和你手动右键保存图片的位置是同一个地方。文件从不经过任何第三方服务。

## 四、第三方服务

本扩展**不接入**任何第三方服务，包括但不限于：分析统计、广告、
错误上报、云端备份、账号体系、遥测。

## 五、Cookie 与跟踪

本扩展不读写任何 Cookie，不使用任何跟踪技术。

## 六、你的控制权

- **关闭扩展**：所有设置与下载历史随扩展数据一起保留在本机；卸载扩展即彻底删除。
- **清空历史**：在扩展的下载历史里可以单独清除记录。
- **改保存位置**：在扩展的设置页里可以随时改下载目录。

## 七、变更

政策如有变更，会在本文档里更新日期，并写进扩展的更新说明里。

## 八、联系

## 附：使用边界

本扩展只下载你在小红书网页上**主动查看**的内容，用于个人收藏与备份。
