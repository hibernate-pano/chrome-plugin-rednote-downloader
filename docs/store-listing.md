## 详细说明

```
在小红书网页上一键保存视频与图片：原始画质、真实进度、批量可选、命名可预期。

【笔记页】
· 打开任意笔记，右下角出现下载按钮，点击展开面板
· 自动识别这条笔记里的全部视频与图片，显示尺寸、时长、文件大小
· 每条都能单独下载，也能复制直链
· 顶部可切换「只下载视频 / 只下载图片」，列表和按钮跟着变
· 还能切换保存结构：按笔记 / 按作者 / 全部平铺

【用户主页】
· 打开任意用户主页，点一下就扫描这个账号的全部笔记
· 网格展示，按「视频 / 图集」分类，可全选、反选、按需勾选
· 选好后一键批量下载
· 另有「下载内容」筛选：只下视频、或者只下图片
· 保存结构在面板里随时可切

【下载过程】
· 每一行都有独立的进度条、速度与字节数
· 失败会写明原因，可以单独重试
· 网络瞬断会自动退避重试
· 完成后明确告诉你保存了几个文件

【保存位置与命名】
· 默认：小红书下载/{作者}/{标题}/1.mp4、2.jpg…
· 根文件夹、命名模板、图片格式、并发数都可以在设置页改
· 设置页实时预览完整保存路径，所见即所得
· 走 Chrome 的下载管理器：文件进你的「下载」目录，下载栏里看得到
· 文件特别多时可以打包成一个 zip

【隐私】
· 不收集、不上传、不共享任何数据
· 没有账号、没有服务器、没有统计
· 设置和下载记录只存在你自己的浏览器里

【使用须知】
本工具只下载你在小红书网页上主动查看的内容，用于个人收藏与备份。
请尊重内容作者的版权，不要用于二次分发或商业用途。
大量下载原始画质可能触发平台限流，请合理使用。
```

## 权限说明

| 权限 | 提交给商店的理由 |
| --- | --- |
| `downloads` | 把解析出来的视频和图片保存到用户自己的下载目录，这是扩展的核心功能。 |
| `storage` | 在用户本机保存设置（保存路径、命名模板、图片格式、并发数、界面偏好）与最近 50 条下载任务的完成情况。不上传、不同步。 |
| `offscreen` | 批量文件打包成 zip 时需要。Chrome 的 offscreen API 是完成大批量文件操作（几百个文件合成一个包）的官方途径，不使用任何外部服务。 |
| 主机权限 `https://*.xiaohongshu.com/*` | 只在小红书网页上读取页面已经加载的数据，从中解析视频与图片的下载地址。不访问其它任何网站。 |
